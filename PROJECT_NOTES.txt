Comportamento atual da autenticacao
- Register cria usuario com email normalizado em minusculo.
- Senha nao e salva pura no banco.
- Senha e salva usando `PasswordHasher<Usuario>`.
- Login valida email e senha.
- Register e login retornam JWT.
- Token inclui claims do usuario:
  - `NameIdentifier` com o Id do usuario
  - `Name` com o nome
  - `Email` com o email

Criacao autenticada de artigo
- `POST /api/artigo` agora usa `[Authorize]`.
- `CreateArtigoDto` nao recebe mais `AutorId`.
- O autor do artigo agora vem do token JWT.
- O controller le `ClaimTypes.NameIdentifier` para obter o Id do usuario autenticado.
- O repository valida se o usuario existe e esta ativo antes de criar o artigo.
- `GET /api/artigo` e `GET /api/artigo/{id}` continuam publicos para visitantes.

- Requisicao precisa enviar header:

- Body esperado:
