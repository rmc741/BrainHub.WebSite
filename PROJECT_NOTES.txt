Objetivo do produto
- Criar uma plataforma/forum de artigos.
- Usuarios poderao ler artigos.
- Usuarios cadastrados poderao criar artigos.
- Usuarios cadastrados poderao comentar em artigos.

Estado atual do front-end
- Projeto em React + TypeScript + Vite.
- Usa React Router.
- A home atualmente renderiza secoes de Artigos, SobreNos e Contato dentro da propria pagina.
- O front ja consome artigos da API em:
  - src/pages/artigos/Artigos.tsx
- Endpoint usado no front hoje:
  - https://localhost:7072/api/artigo

Observacoes sobre o front
- O componente de artigos espera algo parecido com:
  - id
  - titulo
  - resumo
  - dataPublicacao
- Existe sinal de problema de codificacao em alguns textos.
- A estrutura de rotas ainda pode ser simplificada depois.

Estado atual do back-end
- Projeto em ASP.NET Core + Entity Framework Core + SQLite.
- Ja existe:
  - Program.cs configurando DbContext, CORS, Controllers e Swagger
  - Entidade Artigo
  - Configuracao ArtigoConfiguration
  - ArtigoController
  - ArtigoRepository
  - Banco SQLite local

- O front espera "resumo", mas a entidade Artigo atual nao tem esse campo.
- O front usa algo como dataPublicacao, enquanto o back hoje tem DataCriacao.
- O back ainda usa Autor como texto livre.
